READING THE DATA

A few useful distinctions.

Task completion
Completed runs divided by terminal runs: completed, failed, or cancelled. Running and paused runs are shown separately.
Delivery checks
Recorded checks on expected outputs. Passing them does not establish scientific correctness.
Agent time & human wait
Agent time excludes recorded waits for human input. Elapsed time includes both. Medians include terminal runs only.
Reported tokens
The sum of known, reported input and output tokens. Missing usage stays unknown; coverage is shown next to the total. Cost is unavailable in this preview.
Tool calls & skills
Each completed call is counted once. Skill loading is a distinct event. A repeated call is a signal to inspect, not proof of wasted work.
Human interventions
Approvals and clarifications are normal collaboration. Corrections and takeovers require an explicit user label or recorded action.
Model comparisons
Descriptive observations on the selected task mix. Different sample sizes, task types and agent settings can explain apparent differences.
Data boundaries
All records here are synthetic. The production design uses execution metadata and check outcomes; private messages, reasoning, research files and credentials stay outside analytics.
